파일이동할 폴더

정리한 파일은 선택한 폴더 안에 분류 폴더를 만들어 옮겨요. 숨김 폴더(.으로 시작)와 node_modules는 건너뜁니다.

초안·시안·최종·찐최종·v2 같은 꼬리표를 떼고 같은 이름끼리 묶어요.

순서는 수정 시각 기준이에요(브라우저는 생성 시각을 알려주지 않아요). 부모는 앞선 파일 중 이름·내용(텍스트 파일)·크기가 가장 비슷한 파일이에요. 새 이름의 _from-v02는 직전 버전이 아니라 v02에서 갈라졌다는 뜻이에요. 웹페이지는 진짜 바로가기(.lnk)를 만들 수 없어서, 대신 경로가 담긴 _목록.txt를 만들어요.

크기·해상도가 달라도 같은 그림이면 묶어요(축소본, 재저장본). 가장 큰 해상도 파일을 남기는 쪽으로 기본 체크돼요. 회전·좌우반전·크게 잘린 이미지는 못 찾아요. jpg·png·webp·bmp·gif·avif만 지원해요.

기준을 고르면 삭제 후보를 보여줘요. 후보는 처음에 체크되어 있지 않으니 직접 고르세요.

브라우저는 ‘마지막 사용 시각’을 알려주지 않아서 수정 시각으로 판단해요. 읽기만 한 파일도 오래 안 쓴 걸로 나올 수 있어요. 버전 기준은 ‘비슷한 파일·버전’ 탭과 같은 방식으로 묶어요.

이동·이름 변경·삭제를 되돌릴 수 있어요. 기록은 선택한 폴더의 .정리기 폴더에 저장돼요.

파일·폴더 이름에 목적과 유효기간을 적어요. 형식: 견적서{발표용}[~2026-12-31].pdf — 목적이 끝나면 {발표용✔}. 직접 이렇게 이름을 지어도 인식돼요.

현재 이름바꿀 이름

목적이나 유효기간 중 비워 둔 칸은 기존 값을 유지해요. 폴더 이름 바꾸기는 안의 파일을 새 폴더로 옮기는 방식이라 큰 폴더는 오래 걸려요(되돌리기 가능). 체크한 항목은 ‘정리 추천’의 규칙 6에 따라 만료·달성 시 삭제 후보에 올라요.
